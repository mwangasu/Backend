# CivicLens AI — Frontend

React + Vite frontend for CivicLens AI. See the [repo root README](../README.md) for the full project overview, setup instructions, and deployment guide.

## Quick start

```bash
npm install
npm run dev
```

Talks to the backend at `VITE_API_URL` (defaults to `http://127.0.0.1:8000/api/`).
